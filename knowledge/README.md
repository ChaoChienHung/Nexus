# Nexus Built-In Example Knowledge Base

This `knowledge/` directory contains a minimal **sample dataset** (2 example Document Bundles, 8 Ontology Concepts, and 3 References) so anyone cloning the public `Nexus` repository can immediately run `cd app && npm install && npm run dev` and explore the Reader, Sentence Comments, Terminology Inspector, and Knowledge Graph.

For your real personal notes, you can point Nexus at a separate **Private Vault repository** (e.g., `Nexus-Vault`) via `NEXUS_KNOWLEDGE_DIR` in `app/.env.local`. See [docs/guides/private-vault-setup.md](../docs/guides/private-vault-setup.md).
